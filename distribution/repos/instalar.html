Heisuca Voltar para Apps

Instalação via Repositório Beta Desktop

Suporte exclusivo para Linux x64 sob Wayland (Ubuntu 24.04+ e Fedora 45). Não há suporte para ambientes X11, macOS ou arquiteturas ARM.

A configuração do repositório é realizada uma única vez. Após a conclusão deste passo a passo, o sistema receberá todas as atualizações futuras automaticamente pelo próprio gerenciador de pacotes padrão (apt ou dnf).

Ubuntu 24.04+ (APT)

Configuração de keyring seguro sem apt-key obsoleta e formato deb822:

sudo apt update && sudo apt install curl ca-certificates gnupg
sudo install -d -m0755 /etc/apt/keyrings
curl -fsSL https://heisuca.docaio.com.br/pacotes/repos/apt/heisuca-archive-keyring.gpg | sudo tee /etc/apt/keyrings/heisuca-archive-keyring.gpg >/dev/null
sudo chmod 0644 /etc/apt/keyrings/heisuca-archive-keyring.gpg
curl -fsSL https://heisuca.docaio.com.br/pacotes/repos/apt/heisuca.sources | sudo tee /etc/apt/sources.list.d/heisuca.sources >/dev/null
sudo apt update
sudo apt install heisuca
Fedora 45 (DNF / RPM)

Importação de chave GPG e repositório RPM (verificação gpgcheck e repo_gpgcheck integradas):

sudo rpm --import https://heisuca.docaio.com.br/pacotes/repos/rpm/RPM-GPG-KEY-heisuca.asc
sudo curl -fsSL https://heisuca.docaio.com.br/pacotes/repos/rpm/heisuca.repo -o /etc/yum.repos.d/heisuca.repo
sudo dnf install heisuca
